# Blocker — changelog

Blocker (formerly Dependency Planner). Semantic Versioning: MAJOR.MINOR.PATCH.

- **3.43.1** (2026-09-01) — Fix: a Ready card in an open milestone more than one step deep couldn't be started (3.36.0 applied a milestone rule to cards). Ready work is always startable — Start is shown again and double-click starts, on the board and in the Ready list. The milestone's depth is now reported as a note rather than a refusal; the Ready entry keeps its muted marker and tooltip, and milestone status in Direction and the calendar is unchanged.
- **3.43.0** (2026-08-31) — Audit fixes. Dropping a card on Requires threw on a dead reference to an undeclared variable and left the drag stuck; the handler finishes properly and addDep now reports the card that blocked the link. Undo no longer wipes lastSeen: the project shape is written once (project()) and shared by the file, the session copy and undo, and layout scratch (x/y/col) is kept out of all three. layout() is geometry only — Ready stamps and the in-progress guard moved to derive(), which undo does not run, so restoring a snapshot reproduces it exactly. The stat line touches the DOM only when its numbers change, the palette is read from the stylesheet once, and pending reviews and tag lookups go through a per-frame set and the card index (60 cards: 732 getComputedStyle calls and 15 ms per frame became 0 and 2.8 ms). A project file that fails to parse or migrate no longer replaces the open project. Done obeys the tag filter, like the board and Ready. Jump-to-card, milestone removal and part-adding exist once each. Uncaught errors surface as a message instead of dying in the console.
- **3.42.0** (2026-08-31) — Standalone: the artifact-runtime storage API is gone. The session copy and every UI preference (sidebar, panes, active tab, window positions, activity filters) live in localStorage, so the app runs from a plain file or any static host. Styles moved out to blocker.css and the version history to CHANGELOG.md.
